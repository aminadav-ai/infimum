# Contributing to Infimum

Thank you for your interest in contributing to **Infimum**!

## How to Contribute

1. Fork the repository and create a feature branch from `main`.
2. Ensure all workspace checks and tests pass locally:
   ```bash
   cargo test --workspace
   ```
3. Keep pull requests focused and well-tested.
